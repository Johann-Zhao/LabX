# LabX —— 高校创新空间的体验型智能体

> 不止是一个物料借还系统。LabX 把"借一件物料"变成"一次被陪伴的学习"：
> 借出即推送上手知识，卡住时智能体五步排障，归还时心得沉淀为社区经验，同学上传的资料经审核回流知识库——物料流转一圈，知识就厚一层。

## 为什么不一样（四大亮点）

### 1. Harness 架构：智能助手的"方向盘"不在模型里

大模型只是引擎。真正决定智能体"什么时候问、问什么、调什么工具、怎么兜底"的，是模型外围的 harness（脚手架）层——LabX 的 harness 就是编排引擎 `backend/orchestrator.py`：

- **意图识别 + 槽位状态机**：先判断排障 / 求用法 / 想做项目 / 查库存 / 闲聊；槽位不齐就逐轮澄清给候选（"是哪个物料？"），问清为止，绝不硬答
- **回答阶梯**：本地知识库（IDF 重排阈值判定真命中才敢用）→ 联网检索（官方资料优先）→ 通用经验（诚实声明）→ 断网离线兜底，每层都有明确进退条件
- **上下文记忆**：跨轮次指代沿用（"那怎么接线"记住上一轮的物料）、澄清挂起/恢复、逃生项"不用问了，直接回答"
- **过程显化**：harness 的每个真实动作（检索/联网/识别图片）通过状态回调流式推给前端，用户看到的是执行日志而不是加载动画
- **防幻觉护栏**：BOM 清单由 LLM 自由生成但必须标物料目录 ID，后端逐件校验，对不上就打回——模型的创造力被约束在真实库存之内
- **多模态通路**：带附件的消息由 harness 直接路由到 vision / 文档解析通路，文件即问题主体，不再走文字意图分类
- **降级哲学**：所有 LLM 调用统一封装，任何异常就地降级（摘录本地卡片 → 预置兜底），harness 保证系统永远"有回答"

### 2. MCP 架构：能力即工具，四个 MCP Server

用 FastMCP 把核心能力薄封装成四个 MCP Server（`backend/mcp_servers/`），智能体编排引擎按需调用：

| Server | 能力 |
|---|---|
| `material-mcp` | 物料检索、库存、借还 |
| `knowledge-mcp` | 知识卡片检索、经验入库 |
| `user-mcp` | 用户权限、借用历史 |
| `file-mcp` | 资料解析、待审列表、审核入库 |

今天它们是进程内模块，明天可以原样拆成独立服务、接给任何 MCP 客户端——架构上限不被演示锁死。

### 3. 控制台式体验设计

- 登录前 6 屏滚动叙事开屏（暗场 + 点阵粒子 canvas + 鼠标斥力 + 终端卡片），把产品理念讲在登录之前
- 主界面三栏控制台：左轨能力矩阵 + 系统状态读数，中央对话控制台（在线 LED、终端日志风过程显化），右轨用户读数 + 物料精选
- 一套响应式页面适配桌面宽屏到 375px 手机，深浅双主题，设计令牌化管理（`docs/design/labx-ui.md`）

### 4. 社区经验闭环：每个使用者都是贡献者

- 归还物料时 LLM 根据借用场景生成心得草稿，一键提交沉淀为可检索的社区经验
- 同学手里有好资料可上传投稿，**管理员审核通过**才转为知识卡片并入向量库——知识库自己会长
- 下一位同学借同一件物料时，第一条推送就是"前一位同学提醒"

## 功能全景

- **物料借还**：库存原子扣减（并发安全）、借期分级（≤30 天直接借出 / >30 天转人工审核）、安全等级管控（advanced 首次借用安全确认 / professional 教师审批）
- **管理台** `/admin`：审核申请、当前在借、全部流水、批量借出、录入物料、资料审核
- **登录权限**：学生 / 管理员双角色路由守卫

## 技术栈

- **前端**：Vue 3（`<script setup>`）+ Vite + Element Plus + GSAP，axios 统一走 `/api` 相对路径
- **后端**：Python 3.13 + FastAPI + SQLAlchemy + SQLite（原子条件更新防超卖）
- **RAG**：Chroma 本地持久化 + 纯 Python n-gram 哈希向量 + IDF 重排（**断网可跑**，45+ 卡片暴力重排零成本）
- **LLM**：DeepSeek `deepseek-v4-flash-vision-exp`（OpenAI 兼容接口），统一封装于 `llm.py`，`LABX_LLM_MOCK=true` 一键断网兜底


## 未来愿景：从实验室到学院的综合性智能体

LabX 今天在创新空间管物料，但它验证的是一套可迁移的范式——**harness 编排 + MCP 工具化 + 知识闭环**：

- **更多场景**：设备预约、工位管理、竞赛组队、项目档案，都走同一个"对话 → 工具 → 沉淀"闭环
- **更多工具**：新能力只需新增一个 MCP Server，编排引擎零改动接入
- **更厚的知识**：每个实验室的本地知识库持续生长，学院级汇总检索
- **更深的智能体**：从"问答助手"到"主动助理"——借用到期主动提醒、项目关键节点主动推送资料

LabX 的终态，是学院里每个空间、每件设备、每条经验背后都有一个可对话的智能体。
