## 第一步：认识两件套并组装

- **探针**（两叉）——插进土壤的部分
- **小板**（LM393 比较器 + 蓝色电位器 + 4 针排针 + 探针 2 脚座）
- 用附带的**双头线**把探针和小板连起来：一头插小板 2 脚座，另一头夹住探针两叉，**夹紧**（线松是"读数乱跳"的头号原因）

## 第二步：接线（断电操作！）

| HL-69 小板 | 接到 Arduino Uno |
|---|---|
| VCC | 5V |
| GND | GND |
| AO | A0 |
| DO | 先不接（后面要用开关量再接 D2） |

杜邦线直插即可，不需要面包板。接完检查一遍再上电。

## 第三步：烧录 + 串口

Arduino IDE 新建 sketch，粘贴 DFRobot 官方样例代码：

```cpp
void setup(){
  Serial.begin(57600);   // 波特率必须 57600
}

void loop(){
  Serial.print("Moisture Sensor Value:");
  Serial.println(analogRead(A0));
  delay(100);
}
```

上传后打开串口监视器，波特率选 **57600**（不是默认的 9600！）。

**预期输出**（每 100ms 一行）：

```
Moisture Sensor Value:520
Moisture Sensor Value:501
Moisture Sensor Value:488
```

**三分钟标定流程**（最关键的一步）：
1. 探针**悬空**（空气中）→ 记一个值（干参考）
2. 插进**干土** → 记一个值
3. 插进**水杯** → 记一个值
4. 判断方向：你的模块是"越湿数值越大"还是"越湿数值越小"？写进代码注释里

DFRobot 官方参考区间（SEN0114 方向，湿 = 大）：`0~300 干土 / 300~700 湿润 / 700~950 泡水`。**克隆模块方向可能相反，以你实测为准。**

## 没输出？第一查什么

1. **波特率**是不是 57600（串口监视器右下角下拉框）
2. **双头线**是否夹紧探针两叉、有没有松
3. AO 是否插在 **A0**（代码里读的是 A0）
4. 5V / GND 是否接对，小板上的电源灯亮不亮
5. 换 DO 试：把 AO 拔了，DO 接 D2，烧 `digitalRead` 打印——电位器能调翻转点，可排查小板是否活着
