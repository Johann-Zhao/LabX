## 需要准备

| 东西 | 说明 |
|---|---|
| 电脑 + USB 线 | 学习板的 USB 口既能供电也能下载程序（要能传数据的线） |
| Keil C51 | 官网 https://www.keil.com 下载 C51 版（uVision），写 C 代码、编译生成 .hex |
| STC-ISP | STC 官方下载软件（官方页面提供 v4.88），负责把 .hex 烧进单片机 |
| CH340 驱动 | 学习板 USB 转串口芯片（多数板子是 CH340）的驱动，装好后才能看到 COM 口 |

## 第一步：装驱动，确认 COM 口

1. 用 USB 线把学习板连到电脑（板子电源开关打开）。
2. 电脑第一次会提示安装驱动，按提示装 CH340 驱动（普中/江协等教程配套驱动包里有；也可以搜 CH340 官方驱动）。
3. 打开"设备管理器"→ 端口（COM 和 LPT），应看到 `USB-SERIAL CH340 (COMx)`。
4. **看不到 COM 口 = 后面全做不了**，先解决驱动问题（见"常见错误"卡片第 1 条）。

## 第二步：Keil 建工程，写代码

1. 打开 Keil uVision：Project → New uVision Project，起名存盘（如 `led`）。
2. 芯片选择窗口搜 `STC89C52RC`（Keil 器件库里有 STC 项；没有就选 Atmel 的 `AT89C52` 也行，两者 8051 内核兼容）。
3. 左侧 Source Group 1 上右键 → Add New Item → 选 C File，命名 `main.c`。
4. 粘贴下面代码（板载 LED 一般在 P2 口，**多数学习板低电平点亮**，以板子丝印为准）：

```c
#include <reg52.h>

sbit LED = P2^0;          // 板载 LED 所在引脚，看板子丝印改
                          // 有的板子在 P1^0，有的在 P2^0

void delay(unsigned int t) {
    while (t--);          // 简单延时，Keil 默认优化级别下有效
}

void main(void) {
    while (1) {
        LED = 0;          // 低电平点亮（共阳接法）
        delay(50000);
        LED = 1;          // 高电平熄灭
        delay(50000);
    }
}
```

5. 点"魔法棒"（Options for Target）→ Output 页 → 勾选 **Create HEX File**（不勾就没有 .hex 可下载！）。
6. 点 Build（或 F7）编译，下方 Output 窗口应出现 `0 Error(s)`。

## 第三步：STC-ISP 下载（关键：冷启动）

1. 打开 STC-ISP，单片机型号选 **STC89C52RC**。
2. 串口号选设备管理器里看到的那个 COM 口；波特率默认即可（或选低一点如 2400 更稳）。
3. 打开程序文件 → 选中刚生成的 `led.hex`（在工程文件夹 Objects 目录下）。
4. 点"下载/编程"，看提示"正在检测目标单片机"。
5. **立刻把学习板断电（关电源开关或拔 USB）再重新上电**——这一步叫"冷启动"，STC 单片机必须靠它进入 ISP 下载模式。提示变"握手成功"、进度条走完，程序就进去了。

## 预期现象

烧录完成瞬间板载 LED 开始以约 0.5 秒间隔闪烁。改 `delay` 的数值再编译下载，闪烁会变快/变慢——程序真正跑起来了。

## 失败第一查

进度条卡在"正在检测目标单片机" → 九成是**没做冷启动**（断电-上电那一步）；其次是 COM 口选错。详见"常见错误"卡片。
