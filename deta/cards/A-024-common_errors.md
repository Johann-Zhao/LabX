## 详细说明

### 1. 供电不足：红灯亮但反复重启 / 开机死机 / USB 设备掉线
**现象**：插电后电源红灯亮，绿灯闪两下就灭，循环重启；或者带显示器时桌面打开到一半黑屏重启；外接硬盘/键盘多时设备随机掉线。
**原因**：Pi 4B 官方要求 **5V / 3A**（官方 15W USB-C 电源）。手机充电器（5V 1A/2A）或劣质线材带不动，电压一跌就重启——这是 Pi 4B 最常见的问题。
**解决**：换官方 15W 电源，或至少满足 5V 3A 的电源 + 支持 3A 的 USB-C 线。减少外设功耗：别用 Pi 给键盘/硬盘同时供电，USB 外设接带独立供电的扩展坞。线材也换粗的短的。
**怎么验证修好了**：插电稳定开机，绿灯持续闪直到系统就绪，不再循环重启；`vcgencmd measure_volts` 输出稳定在 1.8V 左右；满载时也不再掉电。

### 2. 烧录后找不到卡：电脑上 microSD "消失"了 / 提示要格式化
**现象**：用 Imager 烧完后，把卡插回 Windows 电脑，资源管理器里看不到原来那个"U 盘"，或者提示"使用驱动器中的光盘之前需要将其格式化"。
**原因**：这是**正常的**。烧录把卡写成了 Linux 分区格式（ext4 等），Windows 不认识，所以不显示盘符/提示格式化。**千万不要点"格式化"**，格式化会把系统抹掉。
**解决**：什么都不用做。把卡插回 Pi，能启动就说明烧录成功。想确认系统是否在卡上：Windows 磁盘管理里能看到卡被分成了几个分区（含一个 FAT 的 boot 分区——那个有时可见）。
**怎么验证修好了**：卡插进 Pi，上电后绿灯闪烁、系统能启动；SSH 能登录。

### 3. 5V 直接怼 GPIO：引脚损坏、外设烧毁
**现象**：接了 5V 输出的传感器/舵机/继电器的信号线到 GPIO 后，引脚失灵、读数永远不对，甚至整个板子异常；LED 串 5V 引脚不串电阻直接烧灯。
**原因**：Pi 的 GPIO 是 **3.3V 逻辑**，官方明确 GPIO 不耐受 5V。5V 信号灌进 GPIO 会烧坏 BCM2711 芯片内部电路，损坏不可逆。5V 引脚（物理 2、4）只用来给 5V 外设**供电**，绝不能把 5V 接到 GPIO 信号脚。
**解决**：所有 GPIO 信号按 3.3V 设计：传感器模块优先买 3.3V 版本；5V 输出的模块加电平转换器（如逻辑电平转换板）或电阻分压（如 1kΩ+2kΩ 分压到 3.3V）；驱动舵机/继电器用独立的 5V 电源 + 光耦或三极管隔离。接任何线前先确认信号电平，拿不准就用万用表量。
**怎么验证修好了**：新换 GPIO 引脚 + 电平转换后的接线，程序能正常读/写；用万用表确认信号线高电平是 3.3V 而不是 5V。注意：已经烧掉的引脚不会自己恢复，只能换引脚用。

### 4. SSH 连不上
**现象**：`ssh 用户名@IP` 报 `Connection timed out`、`Connection refused` 或一直卡住。
**原因**：按频率排序——(a) Imager 设置里没勾"启用 SSH"（无头模式系统默认**不开** SSH）；(b) Wi-Fi 的 SSID/密码配错，Pi 根本没上网；(c) 电脑和 Pi 不在同一网段（比如一个在 192.168.1.x 一个在 192.168.2.x）；(d) IP 记错或主机名不对。
**解决**：(a) 重烧卡，Imager 高级设置勾"启用 SSH"（选"使用密码认证"并设好账号密码）；(b) 重配 Wi-Fi，注意 5G 频段兼容性，实验室路由器建议用 2.4G 频段；(c) 查路由器后台里 Pi 的实际 IP，或手机热点验证；（d) 用 `ping` 试 IP 是否通。
**怎么验证修好了**：`ping` 通 → `ssh` 登录成功看到 `$` 提示符。绿灯在网络活动时明显闪烁。如果还连不上，插网线（自动获得 IP，最稳）排除 Wi-Fi 因素。

### 5. 开机红灯亮、绿灯完全不闪（进阶坑）
**现象**：插电后只有电源红灯亮，绿灯从头到尾不闪，屏幕无信号。
**原因**：系统根本没起来。常见原因：卡没插到位（卡槽没卡住）、卡不是烧录好的卡、烧录中断（烧录时拔卡）、卡太旧太慢（官方建议 Class 10/A1 以上）。
**解决**：重新插卡确认卡到位（标签面朝外，Pi 3/4 的卡槽插到底自动锁住，拔卡轻拉）；用 Imager 重烧一遍，烧录过程中别动卡；换一张高速卡。
**怎么验证修好了**：重新上电，绿灯在 1~2 秒内开始规律闪烁，最终进入系统（SSH 可登录或桌面出现）。
