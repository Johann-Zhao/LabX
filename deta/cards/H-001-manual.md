## 关键参数

| 参数 | 值 |
|---|---|
| 孔数 | 830 孔（中间端子区 + 两侧电源轨，具体布局以实物为准） |
| 孔间距 | 0.1 英寸 = 2.54mm 标准 |
| 端子行结构 | 每行 10 孔，中间凹槽隔成左右各 5 孔；同侧 5 孔内部连通 |
| 凹槽（隔离槽） | 左右两半不连通；DIP 芯片跨凹槽插放 |
| 电源轨 | 左右两侧竖条，同侧整条连通，标 + / -，红色为正蓝色为负 |
| 左右电源轨关系 | 默认互不相通，要让两侧都有电需用跳线桥接 |
| 连接方式 | 孔内弹簧金属夹夹持引脚，免焊接、可反复插拔 |
| 配套线材 | 65 根杜邦线（公母类型以实物为准，多数为公对公） |

## 结构认识（文字化示意图）

```
            830 孔面包板（俯视图）
 ┌────────────────────────────────────────────┐
 │ 左电源轨 │      端子区（每行 10 孔）       │ 右电源轨 │
 ├──────────┤                                ├──────────┤
 │  +  ●●   │  ● ● ● ● ● │ ● ● ● ● ● │    ●●  +  │
 │  +  ●●   │  ● ● ● ● ● │ ● ● ● ● ● │    ●●  +  │
 │  -  ●●   │  ● ● ● ● ● │ ● ● ● ● ● │    ●●  -  │
 │  -  ●●   │  ● ● ● ● ● │ ● ● ● ● ● │    ●●  -  │
 │  ...     │     ↑ 凹槽 ↑（左右不连通）     │   ...   │
 └──────────┴────────────────────────────────┴──────────┘

 ● = 孔
 · 同一行左右各 5 个 ● 内部金属连通（同行同侧 5 孔 = 一个节点）
 · 凹槽把左右隔开：左边 5 孔和右边 5 孔互不相通
 · 电源轨整条竖着连通：上面插电源，下面就能取电
 · 行号（数字）列标（字母）只用于定位，不影响电气
```

各部分说明：

- **端子行**：中间大区域的横排孔，每行左右各 5 个连通，是搭电路的主力区域
- **凹槽（隔离槽）**：板中央的长槽。LED 两脚、DIP 芯片引脚要跨着它插，这样左右两半不会短路
- **电源轨**：两侧竖条，通常整条连通，标 +（红）/-（蓝）。注意：**左侧电源轨和右侧电源轨不是连通的**，两边都要供电就得用跳线把 + 连 +、- 连 -（SparkFun 明确提示）
- **接线柱**：部分面包板配金属接线柱（binding posts），可接电源线或香蕉插头，看实物有没有
- **杜邦线**：公头插面包板孔、母头套元件引脚/模块排针；颜色规范：红=正、黑=负，方便查错

## 适用场景

- 直插元件电路搭建：LED、电阻、电容、按钮、DIP 芯片（如 LM358、ATmega328）
- Arduino/单片机实验的快速原型验证
- 教学电路、临时测试、课程设计初期

## 不适用场景

- 贴片元件（SMD）：引脚间距不是 2.54mm，插不进面包板
- 高频信号电路：面包板内部金属条和引脚产生寄生电容/电感，高频信号会失真
- 大电流电路：弹簧夹接触电阻大，超过约 1A 会明显发热
- 成品交付：震动会导致接触不良，最终产品应焊到 PCB 上
