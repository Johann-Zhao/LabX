## 详细说明

### 1. 上传失败 / 一直 "Connecting..."
ESP32 上传最常见的卡点，按顺序排查：
- 按住 **BOOT** 键不松，点上传，看到 "Connecting..." 时松手——强制进下载模式；
- USB 线是不是只能充电不能传数据；
- 串口监视器开着会占用端口，先关掉再上传；
- 开发板型号选 "ESP32S3 Dev Module"，端口选对 COM 口。

### 2. 上电瞬间 LED 闪一下 / 引脚乱跳
GPIO0、GPIO45、GPIO46 是启动配置脚（strapping pin），上电瞬间会输出固定电平来决定启动方式。**别把 LED、继电器、三极管接到 GPIO45/46**，否则每次上电都会闪一下或误动作；GPIO0 是 BOOT 键所在脚，接负载可能影响正常启动。做项目用普通引脚（如 GPIO2、GPIO4、GPIO5）。

### 3. 5V 信号直接怼 GPIO / 模拟口
ESP32-S3 是 3.3V 逻辑：ADC 输入范围 0-3.3V，接 5V 会烧；5V 输出的传感器信号线要经电平转换或电阻分压（如 1kΩ 和 2kΩ 串联，从中间抽头取 3.3V）。用 3.3V 供电的传感器模块可以直连。外接 5V 设备给信号时，先确认设备输出电平再接线。

### 4. USB 供电不足反复重启
开 WiFi 的瞬间电流峰值很大，USB 口或劣质数据线供电不足会导致反复重启。外接设备多时，从 5V 引脚用 5V 电源单独供电（GND 与板子共地），别全指望 USB。
