## 关键参数

| 参数 | 值 |
|---|---|
| 工作电压 | 3~6V DC（额定 5V；电压越低转速/流量越低，约 3V 时明显变慢） |
| 工作电流 | 约 100~200mA（启动瞬间浪涌更高，不同型号差异大，以实测为准） |
| 流量 | 约 80~120 L/H（5V、出水口无阻塞时，实际随扬程/管径下降） |
| 最大扬程 | 约 0.4~1.1m（型号不同差异大；扬程越高流量越小） |
| 类型 | 离心式微型潜水泵（有刷直流电机 + 叶轮） |
| 出水管 | 内径约 5mm 软管，直接套在出水口（管口带倒刺） |
| 接线 | 两根线：红线（+）、黑线（-）；接反会反转不出水 |
| 使用条件 | 完全浸没、清水、禁止干转 |

## 为什么不能直接接 Arduino 引脚（两个原因）

1. **电流不够**：Arduino 一个数字引脚最多安全输出约 20mA，而水泵工作电流 100~200mA、启动瞬间更高——直连会拉垮引脚、烧坏芯片。
2. **反电动势**：水泵本质是直流电机，属于**感性负载**。断电瞬间电机会产生反向电压尖峰，可能击穿驱动它的引脚/芯片。

正确做法：**必须用继电器或 MOSFET 做开关**——Arduino 只发控制信号，水泵的电源走独立供电（USB 5V/1A 充电头或电池盒）。水泵两根线之间建议并一个 1N4001~1N4007 续流二极管（白环一端朝正极），保护开关元件。

## 使用要点（保姆级）

- **先放水，再通电**：泵体完全没入水中（水位没过进水口）才能上电。干转 = 烧泵。
- 出水管别折死、别堵，出水口朝天或受阻会让泵憋压发热。
- 水被抽干、泵露出水面时程序还在开泵 = 干转。自动浇水项目务必加水位检测（浮球开关）或设定安全运行时间。
- 用后先断电，再把泵取出倒空余水晾干。
- 只抽清水；盐水、油、饮料会腐蚀电机。

## 适合 / 不适合

- 适合：自动浇花、小喷泉、鱼缸水循环、桌面水冷小循环、干湿分离演示。
- 不适合：扬程超过 1m 的抽水（扬程只有约 0.4-1.1m）、需要精确恒定流量的场合（离心泵流量随扬程变化）、长期连续运行（有刷泵寿命有限）、任何非清水液体。
