## 这是什么

HL-69（同型：YL-69、FC-28 的电阻式版本）是两件套：**两叉探针**（插土部分）+ **LM393 比较器小板**（信号处理部分）。原理（DFRobot 官方描述）：探针往土壤通电流、测土壤电阻——水越多导电越好、电阻越小；土越干电阻越大。它给的是**相对湿度信号**，不是精确的含水率百分比。

## 关键参数

| 参数 | 值 |
|---|---|
| 供电 | 3.3V 或 5V（DFRobot SEN0114 同型标注） |
| 输出 1：AO | 模拟电压（约 0~VCC，随湿度变化）→ 接 Arduino 模拟脚 |
| 输出 2：DO | 数字电平（0/1，由比较器阈值决定）→ 可直驱继电器 |
| 比较器 | 板载 LM393 |
| 阈值调节 | 板上蓝色电位器（单圈），控制 DO 翻转点 |
| 测量原理 | 土壤电阻法（电阻式），相对值 |

**官方参考读数区间**（DFRobot SEN0114 样例，A0 读值、10bit ADC）：

| 读数 | 土壤状态 |
|---|---|
| 0 ~ 300 | 干土 |
| 300 ~ 700 | 湿润 |
| 700 ~ 950 | 泡水 |

⚠️ 注意：这是 DFRobot 官方模块的方向（湿 = 数值大）。**市面上 HL-69 克隆版方向可能相反**（干 ≈ 1023、湿 ≈ 0），必须按你自己模块实测标定——详见常见错误卡片。

## 引脚定义（小板上通常 4 针）

1. **VCC** —— 3.3V 或 5V
2. **GND** —— 地
3. **DO** —— 数字输出（阈值由电位器设定）
4. **AO** —— 模拟输出 → Arduino 模拟脚（如 A0）

**探针接口**：小板上的 2 脚座，用双头线连到探针两叉（两叉不分正负，但要夹紧）。

## 接线建议

| HL-69 小板 | Arduino Uno |
|---|---|
| VCC | 5V |
| GND | GND |
| AO | A0 |
| DO | D2（可选，用开关量时再接） |

## 适合 / 不适合

✅ 适合：
- **自动浇花**（本件是自动浇花项目的核心件）：阈值判断 → 继电器 → 水泵
- 盆栽缺水提醒、温室土壤监测
- 只要"干/湿"开关量的场景（用 DO）

❌ 不适合：
- 需要精确含水率百分比的实验（它只有相对值，且受土质/盐分影响）
- **长期插在土里**（电解腐蚀，几个月到一年读数失效；DFRobot 官方也推荐更耐腐蚀的电容式 SEN0193 做长期部署）
- 盐分高的土壤或营养液（读数漂移严重）
