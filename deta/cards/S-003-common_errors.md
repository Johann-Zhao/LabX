## 详细说明

### 1. 读数永远是 0 / 读不出来
九成原因是 DATA 脚没接上拉电阻。DHT22 是单总线协议，DATA 脚需要一个 4.7kΩ 上拉电阻拉到 VCC 才能正常通信。面包板搭电路时这个电阻最容易被忘。

### 2. 接线顺序
VCC → 3.3-5V，GND → GND，DATA → 任意数字引脚（如 D2）。**先断电再接线**，接完检查两遍再上电。VCC 和 GND 接反会烧坏。

### 3. 读取超时 / 返回 NaN
DHT22 的采样周期约 2 秒。在 loop 里不加延时连续读取会得到超时或 NaN。用 `delay(2000)` 或 millis() 控制读取节奏。

### 4. 数值漂移
刚上电的前几秒读数不稳定属正常现象，等 2-3 秒再取有效值。
