## 坑 1：读数永远是 0 或 NaN

**现象**：串口输出 `Humidity: 0.00` 或 `Failed to read from DHT sensor!`，怎么换引脚都没用。

**原因**：① 裸传感器的 DATA 脚没接 4.7kΩ 上拉电阻——单总线协议需要上拉电阻才能正常通信，这是新手九成翻车的点；② 跳线松了、接触不良。

**解决**：面包板上从 DATA 所在列 → 4.7kΩ 电阻 → VCC 列；把所有跳线重插一遍按紧。模块版板载已有上拉，确认你用的是模块版而不是裸传感器。

**怎么验证修好了**：上电等 2 秒，串口出现正常数值；轻轻摇动接线，读数不应变化。

## 坑 2：读取超时 / 连续 NaN（读太快）

**现象**：输出隔几行才成功一行，或大量 `Failed to read`。

**原因**：DHT22 最快 0.5Hz——每 2 秒才完成一次测量，loop 里不延时连续读必然失败（Adafruit 官方明确标注 "no more than 0.5 Hz sampling rate"）。

**解决**：loop 里 `delay(2000)`，或用 `millis()` 定时 2 秒读一次；读失败（isnan）直接 return 等下一轮，不要死循环重试。

**怎么验证修好了**：改成 2 秒节奏后每一行都成功输出。

## 坑 3：接反烧坏（不可逆）

**现象**：传感器发烫、冒烟，之后任何接法都没输出——大概率已经永久损坏。

**原因**：VCC 与 GND 接反，或 5V 误接到 DATA 脚。DHT22 内部没有反接保护。

**解决**：**先断电再接线**；插线前按引脚图核对两遍（正面朝自己：VCC / DATA / NC / GND）；确认后先接 GND 再接电源。烧坏的传感器无法修复，只能换新。

**怎么验证修好了**：换新传感器、正确接线后，上电 2 秒内出读数。

## 坑 4：刚上电读不到 / 读数漂移

**现象**：上电后前几秒全 NaN，或数值忽高忽低。

**原因**：DHT22 需要时间完成首次测量（采样周期 2 秒），上电瞬间读不到是正常行为；传感器本身也有个热稳定过程。

**解决**：`setup()` 里先 `delay(2500)` 再首次读取；代码里用 `isnan()` 判断失败就跳过本轮。

**怎么验证修好了**：上电 5 秒后读数稳定，且与室温计/湿度计对照误差在 ±0.5℃ / ±5%RH 以内。

## 坑 5：多颗传感器接到一根数据线上

**现象**：两颗 DHT22 读数互相干扰、时好时坏。

**原因**：DHT22 用的单总线**不是** Dallas 1-Wire 标准协议，不支持总线挂多颗（Adafruit 官方明确说明）。

**解决**：每颗传感器独占一个数据引脚，代码里分别建对象：

```cpp
DHT dht1(2, DHT22);   // 第一颗
DHT dht2(3, DHT22);   // 第二颗，各自独立引脚
```

**怎么验证修好了**：两颗传感器读数各自稳定，互不串扰。
