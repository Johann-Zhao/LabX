## 第 0 步：教师审批（没有就停在这里）

858D 是专业高危设备。先向老师申请使用、登记，请老师演示一遍，**确认老师在现场**再动手。

## 第一步：安全检查（1 分钟）

1. 台面清空易燃物：纸、泡沫、线头、塑料袋全部拿走
2. 检查喷嘴装紧、风口无堵塞（喷嘴必须在**冷却状态**下检查/安装）
3. 确认出风口方向对着工件区，不会对着人或易燃物
4. 准备好镊子和要拆的废板/练习板
- **预期现象**：台面干净、喷嘴牢固、周围 30cm 内无可燃物

## 第二步：开机调温

1. 打开电源开关 → 温度显示出现 **"---"** = 待机状态
2. 按 **温度 + / -** 设温度：新手先用 **300~350℃**
3. **拿起手柄** → 指示灯亮起 = 开始加热；风量旋钮先放**中间档**（新手建议）
4. 等指示灯**快速闪烁** = 温度已稳定，可以开工
- **预期现象**：温度数字快速上升并在设定值稳定；指示灯从常亮变快闪
- 想确认温度手感？把一张纸放在风口 2~3cm 处，纸**马上变黄但不着火** = 温度合适（老手判断法）

## 第三步：拆一颗贴片电阻/电容（练习）

1. 用镊子轻轻夹住元件（或者压住不让它飞）
2. 手柄**垂直对着 PCB**（不要斜着吹），风口距元件 **1~2cm**
3. 围绕元件**四周画小圈**均匀加热，同时观察焊锡
4. 10~20 秒后焊锡熔化、元件轻微松动 → 用镊子轻轻取下
- **预期现象**：元件被完整取下，焊盘上留着亮晶晶的焊锡；**周围的贴片元件一个都没被吹跑**（垂直吹就是为了这个）
- 不要心急：焊锡没熔就硬拔 = 焊盘脱落，板子报废

## 第四步：关机冷却（最容易做错的一步）

1. 手柄**放回支架** → 系统自动切断加热丝电源，指示灯熄灭，风扇继续吹冷却
2. 想让冷却更快？把风量旋钮调到**最大**加速散热
3. 温度降到 100℃ 以下 → 显示回到 **"---"**
4. **等风扇停转、AIR 指示灯熄灭后**，再关电源开关
- **预期现象**：手柄温度逐步下降，显示 "---"，风扇最后停转。直接关开关会缩短加热丝寿命，务必走完流程
- 长时间不用：最后拔掉电源插头

## 第五步：收尾归位

**完全冷却后**才能：拆卸喷嘴、收纳手柄。把拆下的元件和工具归位，报告老师使用完毕。

## 自检清单

- [ ] 老师审批了吗、在场吗
- [ ] 台面无易燃物
- [ ] 温度 300~350℃、风量中间档
- [ ] 垂直吹、1~2cm 距离、画小圈
- [ ] 关机前等风扇停转了吗
