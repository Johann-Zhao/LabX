## 详细说明

### 1. 上传失败 / 找不到端口
按顺序查三件事：工具 → 开发板选没选 "Arduino Uno"；工具 → 端口选没选 COM 口；USB 线是不是只能充电不能传数据。克隆板（板上有 CH340 芯片）要装 CH340 驱动。另外，D0/D1 上接了其他设备会干扰下载，下载时先拔掉。

### 2. 电机/继电器不动或乱动——共地问题
Arduino 的 5V 顶多带几个 LED 和传感器。带电机、继电器、舵机必须单独供电（电池或电源适配器），并且**外设电源的 GND 必须接到 Arduino 的 GND**——两边不共地，信号没有参考电平，I/O 输出等于无效。电机线圈也不能直接接 I/O 引脚，要经过 L298N、ULN2003 这类驱动模块。

### 3. LED 烧了 / 引脚发热
I/O 引脚直接接 LED 不串电阻，电流会超限烧引脚。LED 必须串 220Ω（100Ω-1kΩ 均可）限流电阻。A0-A5 只能测 0-5V 电压，错接 12V 电源或变压器输出会烧掉模拟口。

### 4. 5V 输出接 3.3V 设备
部分传感器和模块是 3.3V 逻辑（如 MPU6050、部分 OLED）。Arduino 的 5V 信号直接接它们的引脚，长期会损坏设备。需要加一个双向逻辑电平转换模块（4 引脚那种）再连接。
