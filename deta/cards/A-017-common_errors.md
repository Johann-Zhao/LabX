## 详细说明（每个坑按 现象 → 原因 → 解决 → 怎么验证 展开）

### 1. 上传失败 / 找不到端口

- **现象**：点上传后报 `avrdude: ser_open(): can't open device` 或"未选择端口"，端口列表是空的。
- **原因**：四件事里至少一件没做对——①工具→开发板没选 **Arduino Uno**；②工具→端口没选 COM 口；③克隆板（板上 CH340 芯片）没装 CH340 驱动；④USB 线只能充电不能传数据。
- **解决**：按顺序查：先选板型 → 再看端口列表（插拔 USB 线，看端口项有没有跟着出现/消失）→ 确认是数据线 → 克隆板装 CH340 驱动。
- **怎么验证修好了**：端口列表里出现 COM 口，上传显示"上传成功"，灯开始闪。

### 2. 上传卡住：avrdude: stk500_getsync() not in sync

- **现象**：能选到端口，但上传一直停在 `stk500_getsync(): not in sync` 或 `programmer is not responding`。
- **原因**：**D0(RX)/D1(TX) 上接了其他设备**（蓝牙模块、GPS、其他串口设备）——下载走的就是这条串口，设备占线或干扰导致 bootloader 收不到数据；也可能是 DTR 自动复位被 shield 挡住了。
- **解决**：拔掉 D0/D1 上的一切外接设备再上传；若还不行，拔掉所有外接线，只留 USB，按一下 RESET 后立刻点上传。
- **怎么验证修好了**：拔线后一次上传成功，程序正常跑起来。

### 3. LED 烧了 / 引脚发热 / 单片机不复位

- **现象**：LED 一接就烧、引脚烫手，甚至整个板子乱跑或电脑提示 USB 过流。
- **原因**：LED 没串限流电阻直连 I/O 引脚——LED 导通后电流远超官方规定的每脚 20mA（极限 40mA），超流会损坏引脚甚至 ATmega328P 本身；短路还会触发板载 USB 保险丝断开（超过 500mA）。
- **解决**：**LED 必须串 220Ω 限流电阻**（100Ω-1kΩ 均可）再接引脚；接线前断电，接完检查一遍再上电。
- **怎么验证修好了**：LED 正常发光不烫手，用万用表电流档串入回路，电流在 20mA 以内；板子一切功能正常。

### 4. 电机/继电器不动、乱动，或一接上单片机就重启

- **现象**：电机接上后要么纹丝不动，要么狂转不停不受控制；继电器吸合瞬间 Uno 重启。
- **原因**：两个经典错误——①**没共地**：外设电源（电池/适配器）的 GND 没接到 Arduino 的 GND，两边参考电平不一致，信号等于无效；②**供电不足**：电机、继电器吸合瞬间电流可达数百 mA，远超 USB 能提供的 500mA，直接把 5V 电压拉垮导致复位。I/O 引脚输出电流最多 20mA，根本推不动电机线圈。
- **解决**：电机/继电器用**独立电源**供电，并**把外设电源 GND 与 Arduino GND 相连（共地）**；电机线圈经过 L298N、ULN2003 这类驱动模块再接引脚，继电器经过三极管或光耦驱动。
- **怎么验证修好了**：给电机发送 PWM，转速平稳可控；继电器吸合时 Uno 不再重启；万用表量 Arduino 5V 引脚电压，设备动作时不低于 4.8V。
