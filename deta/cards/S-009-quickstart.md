## 第一步：接线（断电操作！）

| TCRT5000 模块引脚 | 接到 Arduino Uno |
|---|---|
| VCC | 5V |
| GND | GND |
| DO | D2 |
| AO | 可先不接 |

传感器要**朝下**装，离地约 1cm——别贴地，也别悬太高。

## 第二步：上传代码

Arduino IDE 新建文件，粘贴：

```cpp
void setup() {
  Serial.begin(9600);
  pinMode(2, INPUT);
}

void loop() {
  int v = digitalRead(2);   // 白底/黑线两次读数会不同
  Serial.println(v);
  delay(300);
}
```

工具 → 开发板选 Arduino Uno，端口选 COM 口，上传。打开串口监视器，波特率选 **9600**。

## 第三步：实测 + 调阈值

1. 传感器放在**白纸**上：记下读数（多数模块是 0）；
2. 移到**黑线/黑色胶带**上：记下读数（多数模块是 1）；
3. 两次读数一样？用螺丝刀慢慢转板上的**蓝色电位器**，转到白纸上读数刚变成另一侧为止。

## 循迹小车的接法

两个传感器一左一右装在小车前端，间距略小于黑线宽度，逻辑：

| 情况 | 动作 |
|---|---|
| 左边压到黑线 | 向右修正 |
| 右边压到黑线 | 向左修正 |
| 都没压到 | 直行 |

电机用 L298N 模块驱动，别直接接 Arduino 引脚。
