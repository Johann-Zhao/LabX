## 关键参数

| 参数 | 值 |
|---|---|
| 功率 | 60W（套装标称） |
| 有铅焊锡推荐温度 | 300 ~ 330℃ |
| 无铅焊锡推荐温度 | 350 ~ 380℃ |
| 起步温度（无标准时） | 330 ~ 350℃，按焊锡熔化情况微调 |
| 烙铁头温度上限 | 不宜超过 400℃（Hakko 官方提示：长时间高温会加速氧化） |
| 直插元件推荐头型 | 2mm 凿形头（chisel），平面能同时加热焊盘和引脚 |
| 烙铁头体系 | 可换头结构；936 类焊台用 900M 系列烙铁头，与 Hakko T18 不通用 |
| 换头时机 | 清洁+上锡后焊锡仍成珠不浸润、工作面出现凹坑或露铜 |

## 部件认识（文字化示意图）

```
         可调温电烙铁套装（60W）
 ┌───────────┬──────────────┬────────────┐
 │ 电源线     │ 手柄握把      │ 烙铁头(金属) │
 │ (接220V插座)│ (手握的地方)  │ (接触工件)  │
 └───────────┴──────────────┴────────────┘
        ▲                    ▲
   别让线绊到人       整根金属都是高温！碰＝烫伤

 支架部分（烙铁的"停车位"——不焊就放回去）
 ┌──────────────────────┐
 │ 螺旋支架 + 清洁海绵    │
 │（用前把海绵打湿；      │
 │  或备一个铜丝球）      │
 └──────────────────────┘
```

各部分说明：

- **烙铁头**：整根金属管在通电时可达 300℃ 以上，只能碰工作面以下的杆身，更不要摸尖部。
- **手柄握把**：隔热材质，是唯一能长时间握的地方。
- **支架 + 海绵/铜丝球**：烙铁头的"清洁站"，用前打湿海绵（或放铜丝球），焊前擦掉旧锡和氧化物。
- **温度调节**：旋钮或数字按键，以实物为准；本套装为 60W 可调温，升温约 1~3 分钟。
- **焊锡丝**：套装内焊锡为有铅还是无铅，看包装或问老师，直接决定你设多少度。

## 适用场景

- 直插元件焊接：电阻、电容、LED、排针、模块引脚等
- PCB 焊盘焊接与补焊：虚焊点重焊、导线焊到焊盘
- 配合吸锡器/吸锡带拆直插元件
- 洞洞板电路搭建

## 不适用场景

- 贴片 IC、多脚芯片拆焊（功率和效率不够，请用热风枪 E-002）
- 热缩管收缩、塑料件加热（用热风枪或吹风机，烙铁会把塑料烫变形）
- 大截面线缆、金属壳体的焊接（60W 热量不够，焊不牢）
- 任何"不知道焊不焊得动就硬怼"的操作（超过 5 秒不熔就该检查温度）

## 保养要点（HAKKO 官方流程）

1. **焊前**：加热到位后先用湿海绵/铜丝球擦掉旧锡再焊。焊后再擦反而会加速氧化。
2. **焊中**：保持烙铁头工作面始终被一层焊锡浸润，焊锡不铺开就是氧化了。
3. **温度**：能完成任务就用尽量低的温度，不要图快乱加温。
4. **休息**：超过 5 分钟不焊就关电源；放回支架休息时**不要**擦掉头上的锡，让锡盖住工作面防氧化。
5. **收工**：给烙铁头补一层焊锡保护，放回支架冷却后再收纳。
