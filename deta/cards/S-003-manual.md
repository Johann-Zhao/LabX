## 关键参数

| 参数 | 值 |
|---|---|
| 供电 | 3.3V - 5.5V 直流 |
| 温度量程 | -40 ~ 80℃，精度 ±0.5℃ |
| 湿度量程 | 0 ~ 100%RH，精度 ±2%RH |
| 通信协议 | 单总线（One-Wire） |
| 采样周期 | ≥ 2 秒 |

## 引脚定义（正面朝自己，引脚朝下，从左到右）

1. **VCC** —— 接 3.3V 或 5V
2. **DATA** —— 数据脚，接单片机数字引脚，需 4.7kΩ 上拉电阻
3. **NC** —— 空脚，不接
4. **GND** —— 接地

## 常用库

Arduino IDE 库管理器搜索安装 `DHT sensor library`（Adafruit 出品），示例代码见 quickstart 卡片。
