## 这是什么

DHT22（又称 AM2302）是把"电容式湿度传感器 + 热敏电阻"封装在一起的数字温湿度传感器，内部芯片完成模数转换后直接输出数字信号，**不需要接模拟引脚**。它价格便宜、接线简单，缺点是慢——每 2 秒才能拿到一次新数据。

## 关键参数（来自 Adafruit 官方教程）

| 参数 | 值 |
|---|---|
| 供电电压 | 3 ~ 5V |
| 峰值工作电流 | 2.5mA（转换瞬间） |
| 温度量程 | -40 ~ 80℃ |
| 温度精度 | ±0.5℃ |
| 湿度量程 | 0 ~ 100%RH |
| 湿度精度 | ±2 ~ 5%RH |
| 采样频率 | 最高 0.5Hz（每 2 秒一次新数据） |
| 输出方式 | 单总线数字信号（非标准协议，**不兼容** Dallas 1-Wire） |
| 外形 | 15.1 x 25 x 7.7mm，4 引脚，2.54mm 间距 |

## 引脚定义（正面朝向自己，引脚朝下，从左到右）

1. **VCC** —— 接 3~5V
2. **DATA** —— 数据脚，接 Arduino 数字引脚，需 4.7kΩ 上拉电阻到 VCC
3. **NC** —— 空脚，不接
4. **GND** —— 接地

**模块版（带小 PCB 的 AM2302）**：板载 4.7kΩ 上拉电阻，通常 3 根线——红 = VCC、黄 = DATA、黑 = GND，无需外接电阻。

## 适合 / 不适合

✅ 适合：
- 温室、教室、宿舍的温湿度监测与记录
- 自动浇花联动（湿度低于阈值 → 开继电器）
- 任何不要求高频刷新的室内环境监测

❌ 不适合：
- 需要每秒多次采样的控制回路（物理上限 0.5Hz）
- 多颗传感器共用一条总线的场景（非标准单总线，每颗必须独占数据脚）
- 工业级高精度测量（±2~5%RH 精度是业余级水平）
