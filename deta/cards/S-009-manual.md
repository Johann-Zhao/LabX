## 这是什么

TCRT5000 是 Vishay 出品的**红外反射式光电传感器**：一个 950nm 红外发射 LED + 一个光电晶体管接收管，封装在同一小盒里、朝向同一方向。红外光被表面反射回来，接收管收到光越多导通越强。市售循迹模块在此基础上加了限流电阻、上拉电阻和 **LM393 比较器**，输出 DO（数字）和 AO（模拟）两路信号。

**黑与白的本质**：黑色表面吸收红外光（反射弱），白色表面反射红外光（反射强）——这就是循迹能分辨黑线的原因。

## 关键参数

| 参数 | 值 | 来源 |
|---|---|---|
| 峰值检测距离 | **2.5mm**（信噪比最佳点） | Vishay 数据手册 |
| 有效检测范围 | 0.2 ~ 15mm（相对集电极电流 >20% 时） | Vishay 数据手册 |
| 发射波长 | 950nm（红外，肉眼不可见） | Vishay 数据手册 |
| 发射管最大正向电流 | 60mA（必须有限流电阻，模块板载已加） | Vishay 数据手册 |
| 发射管反向耐压 | 5V | Vishay 数据手册 |
| 接收管 | 光电晶体管，带可见光截止滤光片（daylight blocking filter） | Vishay 数据手册 |
| 封装尺寸 | 10.2 x 5.8 x 7mm | Vishay 数据手册 |
| 模块供电 | 典型 5V（3.3V 可工作但灵敏度下降） | 模块教程 |
| 模块输出 | DO 数字（0/1，电位器调阈值）+ AO 模拟（0~VCC） | 模块教程 |

**AO 数值方向**：反射越强（越靠近/越白），AO 电压越低（接收管导通强、输出被拉低）——白纸的 AO 值比黑线低，这是教程实测结果，但各模块略有差异，以实测为准。

## 引脚定义

**裸传感器 4 脚**（自己搭电路才需要）：

| 脚 | 名称 | 作用 |
|---|---|---|
| 1 | A（阳极） | 发射管正极，经 220~330Ω 电阻接 5V |
| 2 | C（阴极） | 发射管负极，接 GND |
| 3 | C（集电极） | 接收管集电极，经 10kΩ 上拉接 5V，此处取信号 |
| 4 | E（发射极） | 接收管发射极，接 GND |

**循迹模块**（一般 3~4 针，直接用这个）：

| 针 | 作用 |
|---|---|
| VCC | 供电（5V） |
| GND | 地 |
| DO | 数字输出 → Arduino 数字脚 |
| AO | 模拟输出 → Arduino 模拟脚（可选） |

## 接线建议

| 模块 | Arduino Uno |
|---|---|
| VCC | 5V |
| GND | GND |
| DO | D2（任意数字脚） |
| AO | A0（任意模拟脚，可选） |

## 适合 / 不适合

✅ 适合：
- **循迹小车**黑线识别（黑白对比度大的赛道，标配方案）
- 近距离物体检测（1~2cm 内）、挡板/限位检测、编码器测距

❌ 不适合：
- 检测距离超过 15mm 的避障（请用超声波 HC-SR04）
- 阳光直射的室外循迹（阳光含大量红外，会压过信号）
- 低对比度表面（灰砖上的黑线）——信号弱、阈值难调
