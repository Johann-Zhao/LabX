## 关键参数（来自 STC 官方数据手册页）

| 参数 | 值 |
|---|---|
| 内核 | 增强型 80C51，每机器周期 6T 或 12T（可设置） |
| 工作电压 | 3.3V ~ 5.5V（STC89C 系列） |
| 工作频率 | 0 ~ 48MHz @12T；0 ~ 24MHz @6T |
| 程序存储 | 片内 8K Flash，支持 ISP / IAP 在线下载 |
| 数据存储 | 片内 512 字节 RAM；可外扩至 64K 字节 |
| 定时器 | 3 个 16 位定时器/计数器（Timer2 可编程时钟输出到 P1.0） |
| 串口 | 1 个增强型 UART（硬件地址识别、帧错误检测、自带波特率发生器） |
| 中断 | 8 个中断向量，4 级优先级 |
| 看门狗 | 15 位看门狗定时器（带 8 位预分频，一次使能） |
| 复位电路 | 集成 MAX810 专用复位电路 |
| I/O 口 | 最多 39 个可编程 I/O（40 脚 DIP 封装提供 P0~P3 共 32 个） |
| 工作温度 | -40 ~ +85℃（工业级）/ 0 ~ 75℃（商业级） |
| 低功耗 | 空闲模式 + 掉电模式（可被 INT0/INT1/T0/T1/RXD 等唤醒） |

## 引脚定义（40 脚 DIP 直插，标准 8051 脚位）

- **P0.0~P0.7**（39~32 脚）—— 开漏输出口，作普通 IO 用**必须外接上拉电阻**（如 10kΩ 排阻）；也可作外部总线扩展
- **P1.0~P1.7**（1~8 脚）—— 准双向 IO 口，P1.0/P1.1 兼作 Timer2 的 T2/T2EX
- **P2.0~P2.7**（21~28 脚）—— 准双向 IO 口，兼作外部存储器高 8 位地址
- **P3.0~P3.7**（10~17 脚）—— 准双向 IO 口，每个引脚带第二功能：P3.0=RXD 串口接收、P3.1=TXD 串口发送、P3.2=INT0 外部中断0、P3.3=INT1 外部中断1、P3.4=T0 定时器0外部计数、P3.5=T1 定时器1外部计数、P3.6=WR、P3.7=RD
- **VCC（40 脚）** 接 5V；**GND（20 脚）** 接地
- **XTAL1/XTAL2（19/18 脚）** 接晶振（学习板板载，常见 11.0592MHz，串口波特率更准，以板子丝印为准）
- **RST（9 脚）** 复位脚，高电平复位（学习板上有复位按键）

## 学习板板载资源（以板子丝印为准，各厂家略有差异）

典型教学板标配：LED 流水灯（多在 P2/P1 口，低电平点亮）、静态+动态数码管、独立按键、矩阵按键、有源/无源蜂鸣器、USB 转串口下载电路（常见 CH340 芯片）、复位按键、电源开关。

## 适合 / 不适合

**适合**：微机原理/单片机课程入门、跑马灯/数码管/按键/蜂鸣器经典实验、简单传感采集与串口通信、学习 8051 汇编与 C51 基础、毕设简单控制项目。

**不适合**：高算力任务（无操作系统、8 位机）、复杂图形界面、大容量存储、要求高安全性的量产产品（8K Flash 偏小）。
