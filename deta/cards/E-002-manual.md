## 使用前提（先读这条）

858D 属于**专业级高危设备**：出风温度可达 400℃ 以上，能熔化焊锡、烫伤皮肤、烤坏塑料。规则：**必须经过教师审批、登记，并在老师在场时使用**。第一次使用前找老师演示一遍。

## 关键参数

| 参数 | 值 |
|---|---|
| 型号 | 858D 热风拆焊台 |
| 温度范围 | 100 ~ 480℃（部分批次标称至 500℃，以机身铭牌为准） |
| 功率 | 约 650 ~ 700W（不同厂家标称略有差异） |
| 风量 | 旋钮无级可调，最大约 120L/min |
| 温度稳定度 | ±2℃（PID 恒温，指示灯快闪表示已稳定） |
| 常用拆焊温度 | 300 ~ 350℃ |
| 风口与工件最小距离 | 2mm（官方手册规定） |
| 拆小贴片耗时 | 围绕元件加热 10 ~ 20 秒可取下 |
| 附件 | 喷嘴（常见 5/8/10mm）、镊子、小扳手（以实物为准） |

## 部件名称图（文字化示意图）

```
 主机面板：
 ┌──────────────────────────────────────┐
 │ [电源开关] [温度显示] [温度+ / 温度-]  [风量旋钮] │
 └──────────────────────────────────────┘

 手柄（热风枪）：
 [喷嘴] ── [金属加热管] ── [隔热握把] ── [电源线]
    ▲           ▲
 出风口      通电极烫！
 (风口与工件   冷却前绝不碰
  最小距离2mm)

 手柄架：手柄放回支架 → 自动切断加热丝 → 开始强制冷却
```

**面板指示灯含义**（官方手册）：指示灯在温度显示右下角——**常亮**=正在加热；**快速闪烁**=温度已稳定（PID 跟踪中，可以开工）；**熄灭**=冷却中。

## 适用场景

- 拆焊贴片元件：SOIC、CHIP（小贴片电阻电容）、QFP、PLCC 等多脚芯片
- 贴片元件焊接（配合锡膏/焊锡丝）
- 热缩管收缩、助焊剂干燥、胶水/漆层加热软化

## 不适用场景

- 直插元件手工焊接（杀鸡用牛刀，用烙铁 T-005）
- 塑料件加热（热风会把塑料吹变形）
- 对易燃物（纸、布、泡沫）吹风
- 没有老师在场的任何使用（违反使用前提）

## 操作与维护要点（官方手册 + 维修经验）

1. **喷嘴装卸必须等完全冷却**，用小扳手，不要蛮力、不要拧过头
2. 风口保持通畅，出风口堵塞会烧毁加热丝
3. 用小直径喷嘴时，必须用**最大风量 + 较低温度**，并尽快完成操作
4. 风口与工件保持最小 2mm 距离，不要怼着元件吹
5. 首次使用冒少量白烟属正常现象（新加热管表面涂层挥发），通风即可
6. 关机顺序：手柄放回支架 → 等风扇停转、AIR 指示灯熄灭 → 再关电源开关（直接关开关会烧加热丝）

## 常见故障代码

| 显示 | 含义 | 处理 |
|---|---|---|
| S-E | 传感器模块故障 | 停止使用，报老师，需更换发热芯总成 |
| F-1 / F-2 | 失效保护模式（fail-safe） | 停止使用，报老师检修 |
