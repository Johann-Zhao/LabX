# LabX 最终展示 Checklist（阶段 4）

> 使用前先跑：`backend/venv/Scripts/python scripts/preflight.py`，全部 PASS 再开始演示。
> 一键启动：`scripts/start_demo.sh`（Git Bash）或双击 `scripts/start_demo.bat`。

## 0. 环境准备（提前 15 分钟）

- [ ] 一台展示笔记本：后端 8000、前端 5173 已启动
- [ ] 手机与展示机连同一 WiFi；浏览器打开 `http://<展示机IP>:5173`
- [ ] 无痕窗口/新开标签页（保证登录前开屏播放）
- [ ] 网络正常（BOM/联网检索需要）；如断网，设置 `LABX_LLM_MOCK=true` 后重启后端
- [ ] 演示账号可用：学生 `2024001/123456`、管理员 `admin/admin888`

## 1. 登录前开屏（第一印象）

- [ ] 打开页面先播放 6 屏开屏动画：hero → 为什么 LabX → 物料流转 → 知识随行 → 智能助手 → 登录 CTA
- [ ] 点阵 canvas 跟随鼠标有斥力波纹；终端卡片是学生场景（无 npm/git 字样）
- [ ] 跳过按钮 / 结束屏「进入登录」都落到登录页
- [ ] 退出登录后再次回到登录前，开屏会重播

## 2. 学生端主流程（2024001 小王）

- [ ] 登录进入智能助手首页；右轨显示小王与在借件数；学生端没有「管理台」入口
- [ ] 空状态指令行：点「Arduino 还有吗」→ 库存回答 + local_kb 徽标
- [ ] 对话：`你好` / `你能做什么` 快速固定回复
- [ ] 排障：`我的电机不转` → 澄清「是哪个物料」→ 选 L298N（猜的）→ 给五步排查 + 引用卡片
- [ ] 跟进：`那怎么接线` → 沿用上一轮物料，不重新澄清
- [ ] 求用法：`这块板子能做什么` → 澄清 → 选 Arduino → ①是什么 ②能做什么 ③上手 ④学习入口
- [ ] 多模态：点输入栏回形针 → 传一张物料照片问 `这是什么` → **直接识别回答**（不再反问哪个物料）；再传一份 PDF/Word/TXT 问内容
- [ ] 愿望到方案：`我想做自动浇花装置` → 方案步骤 + BOM 卡片（在库/需购分组）→ 一键预约在库件
- [ ] 物料页：搜索/分类筛选、详情页知识卡、借期场景、借用按钮
- [ ] 物料详情页「上传资料」：传一份 txt → 弹鼓励文案（此时进审核队列，详情页还看不到）
- [ ] 借用 DHT22（basic 直接借）→ 结果页出现知识推送（首条含「前一位同学提醒」）
- [ ] 归还 DHT22 → 心得草稿弹出 → 修改提交 → 提示经验入库

## 3. 管理端主流程（admin）

- [ ] admin 登录进入 `/admin`；侧栏 01-06
- [ ] 待审核：学生 2024002 提交 >30 天借用 → admin 通过/驳回
- [ ] 当前在借：显示借用人/物料/应还
- [ ] 全部流水：五态卡片正常
- [ ] 批量借出：选学生 + 多件物料一次借出，部分失败不影响其他
- [ ] 录入物料：分类前缀自动编号；名称重复/分类非法有 1007 提示
- [ ] 资料审核（06）：看到学生刚传的资料 → 点「通过」→ 回到物料详情页能看到新增的 KC-UPLOAD 知识卡片（知识库生长的现场演示）；驳回需填理由
