# LabX UI 设计规范

> 本文档是 LabX 前端唯一设计规范，后续所有页面重做都按它执行。
> 令牌落地在 `frontend/src/styles/tokens.css`（`--lx-*`），Element Plus 主题覆盖在 `frontend/src/styles/element-overrides.css`。
> 参考来源：design-taste-frontend（taste-skill）、impeccable DESIGN.md，已蒸馏为适用于本项目的规则。
>
> 一句话设计定位：**高校创新空间的工具型产品，浅色"未来实验室"语言——暖白底、墨色字、单一实验室绿、细边框、精密网格感，动效克制。**

## 1. 设计原则

1. **工具优先，装饰让位**。LabX 是借还物料、查知识、跑排障的工具。信息层级靠排版和留白，不靠特效。每个视觉元素都要能回答"它帮用户完成了什么"。
2. **细边框代替重阴影**。分组用 1px 细边框（`--lx-border`）和留白；阴影只给真正浮起的层（下拉、弹窗、消息条）。卡片默认不"飘"。
3. **一个绿，用到底**。全站只有一个强调色：实验室绿 `#27794f`。链接、主按钮、选中态、成功态都是它。不许在第七屏突然冒出一个蓝色 CTA。
4. **精密感来自秩序，不是来自装饰**。8px 基网、统一字阶、等宽数字、小圆角刻度。网格线是真实布局的对齐结果，不画装饰性十字线/刻度线。
5. **动效是反馈，不是表演**。动效只表达四件事：hover 反馈、按下反馈、状态切换、加载中。150-400ms，ease-out 类曲线，看完就该消失。

## 2. 色彩系统

### 2.1 浅色主主题（默认）

**品牌色：实验室绿**（由旧主色 `#42b883` 精调：色相不变，加深降饱和）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--lx-green` | `#27794f` | 主按钮、链接、选中态、focus 描边。白字压其上对比度 5.34:1（过 AA） |
| `--lx-green-light-3` | `#68a184` | hover 提亮档 |
| `--lx-green-light-8` | `#d4e4dc` | 选中态描边、`::selection` 底色 |
| `--lx-green-light-9` | `#e9f2ed` | 浅绿底：激活标签、徽标、提示条底色 |
| `--lx-green-dark-2` | `#1f613f` | active 按下加深档 |

**中性色（暖白 + 墨，不用纯白做页面底、不用纯黑 `#000`）**

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--lx-bg-page` | `#f7f7f4` | 页面底色：暖白 |
| `--lx-bg-surface` | `#ffffff` | 卡片、气泡、弹窗 |
| `--lx-bg-subtle` | `#f0f1ed` | 内嵌区块、表头、禁用底 |
| `--lx-bg-hover` | `#f4f5f1` | 列表行 hover |
| `--lx-text-primary` | `#1c2320` | 墨色：标题、正文主力 |
| `--lx-text-regular` | `#3a423d` | 正文 |
| `--lx-text-secondary` | `#656d68` | 次要说明、meta |
| `--lx-text-placeholder` | `#9aa19c` | 占位、弱提示 |
| `--lx-text-disabled` | `#b4b9b5` | 禁用 |
| `--lx-border` | `#d8dbd5` | 默认 1px 细边框 |
| `--lx-border-light` / `--lx-border-lighter` | `#e4e6e1` / `#ebede8` | 更弱的分隔线 |
| `--lx-border-strong` | `#c4c8c1` | 强调边框（输入框 hover） |

**语义色**（低饱和，与主绿同一灰度家族；`--el-*` 已同步映射）

- 成功 `--lx-success: #27794f`（= 主绿，单一强调色纪律）
- 警告 `--lx-warning: #b57f2c` / 底 `--lx-warning-bg: #f8f2ea`
- 危险 `--lx-danger: #be4a43` / 底 `--lx-danger-bg: #f8edec`
- 信息 `--lx-info: #6e7572` / 底 `--lx-info-bg: #f0f1f1`

### 2.2 深色开屏主题（仅开屏动画用）

挂在 `[data-theme="dark"]` 上，是同系深色的"反转"，不是另一套设计：

- 页面底 `--lx-bg-page: #101613`（墨绿近黑，禁纯黑）
- 浮层 `--lx-bg-surface: #171e1a`
- 主文字 `--lx-text-primary: #e9ebe8`
- 主绿提亮为 `--lx-green: #5d9a7b`（深底对比度 5.56:1）
- 边框 `--lx-border: #2c3530`

其余色值见 `tokens.css` 深色段。深色令牌只覆盖颜色，字阶/间距/圆角/动效与浅色共用。

### 2.3 色彩纪律（硬性）

- 页面组件里禁止写死色值，一律 `var(--lx-*)`。
- 一个页面只用这一套色；hover/active 只允许用绿阶梯（light-3 提亮、dark-2 加深），不许发明第五种绿。
- 不用纯黑 `#000000`、纯白页面底（卡片白 `#ffffff` 可以，页面底不行）。
- 阴影染墨色调（`rgba(28,35,32,*)`），不用纯黑阴影。

## 3. 字体与字阶

只用系统字体栈，不引 webfont：

- 中文/正文：`--lx-font-sans`（PingFang SC / Microsoft YaHei / system-ui 栈）
- 数字/编号：`--lx-font-mono`（ui-monospace 栈）。库存数、借用数量、记录号、物料编号、倒计时一律加 `class="lx-num"`（等宽 + tabular-nums，数字不跳动）。

**字阶**（页面只能取这几档，对应 `--lx-text-*`）：

| 档位 | 大小 | 用途 |
|---|---|---|
| xs | 12px | 辅助说明、标签、时间戳 |
| sm | 13px | 次级 UI 文本 |
| base | 14px | 正文、控件默认（对齐 Element 基准） |
| md | 16px | 强调正文、卡片标题 |
| lg | 18px | 区块标题 |
| xl | 20px | 页面标题 |
| 2xl / 3xl / 4xl | 24 / 28 / 32px | 大标题、开屏、关键大数字 |

行高：标题 `--lx-leading-tight: 1.25`，正文/气泡 `--lx-leading: 1.6`。
字重：400 正文 / 500 控件与强调 / 600 标题 / 700 页面标题，共四档，不取中间值。
层级靠"字号 + 字重 + 颜色"三件套，不靠把字放大到吼人。

## 4. 间距体系（8px 基网）

所有内外边距、gap 从 `--lx-space-*` 取：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。
`4px` 是半档，只用于图标与文字之间的微距。禁止出现 7px、13px 这类脱网值。

**响应式容器**（已落在 `style.css` 的 `#app`）：

- `<768px`：全宽，左右内边距 12px
- `≥768px`：限宽 960px 居中
- `≥1280px`：限宽 1200px 居中

多列布局在 `<768px` 必须显式塌成单列，不假设"框架自己会处理"。

## 5. 圆角 / 边框 / 阴影刻度

**圆角一套刻度全站通用**（精密感 = 小圆角，不用大圆）：

- `--lx-radius-sm: 4px` 标签、小控件
- `--lx-radius-base: 6px` 按钮、输入框
- `--lx-radius-md: 8px` 卡片、对话气泡
- `--lx-radius-lg: 12px` 弹窗、抽屉
- `--lx-radius-pill: 999px` 胶囊标签

规则：按钮 6px 的页面不许出现 20px 大圆卡片；同一组件在全站圆角一致。

**边框**：默认 1px `solid var(--lx-border)`；分组先用边框和留白，不够再考虑卡片。

**阴影三档**（只给浮层，平级内容不用）：

- `--lx-shadow-1` 轻微托起（`0 1px 2px`）
- `--lx-shadow-2` 下拉、气泡、消息条（`0 4px 12px`）
- `--lx-shadow-3` 弹窗、抽屉（`0 12px 32px -8px`）

## 6. 动效规范

**三档时长**（`--lx-duration-*`）：

- fast 150ms：hover、按下反馈
- base 250ms：展开收起、显隐切换
- slow 400ms：弹窗进出、页面级过渡

**两条曲线**（禁 linear）：

- `--lx-ease-out: cubic-bezier(0.16, 1, 0.3, 1)`：显形/入场（快出慢收）
- `--lx-ease-standard: cubic-bezier(0.2, 0.8, 0.2, 1)`：状态互转通用

**什么该动**：hover 变色、按下 `translateY(1px)`、加载骨架/进度、气泡逐行显隐、弹窗淡入。只动 `transform`、`opacity` 和颜色/边框这类便宜属性，不动 `width/height/top/left`。

**什么不该动**：无目的的循环动画、无限飘浮的装饰、滚动劫持、入场排队挨个飞进来的"全家桶 stagger"。页面加载完就该是静的。

**降级**：`prefers-reduced-motion: reduce` 时全站动画收敛为瞬时（已在 `style.css` 全局落实）。新写 keyframes 前先看这条有没有覆盖到。

## 7. 组件状态规范

每个可交互组件必须有完整状态闭环，不许只画"静态成功态"：

- **hover**：背景或边框变浅一档（`--lx-bg-hover` / `--lx-border-strong` / 绿 light-3），150ms 过渡。不许无反馈。
- **focus（键盘）**：`:focus-visible` 2px 绿描边（`--lx-green-light-5`），offset 1px——明显但克制。已全局落实，页面不许再 `outline: none` 后不给替代。
- **active（按下）**：`translateY(1px)` 触觉反馈（按钮已全局落实）。
- **disabled**：`--lx-text-disabled` + `--lx-bg-subtle`，`cursor: not-allowed`，不许只做灰色还能点。
- **loading**：优先骨架屏/逐行状态（对齐最终布局形状），其次才是 spinner。ElLoading 走主色。按钮 loading 期间禁重复提交。
- **empty**：空状态 = 一句说明 + 一个引导动作（例："还没有借用记录，去物料页挑一件"），不许只摆一行"暂无数据"。
- **error**：表单错误内联显示在输入框下方；临时性反馈用 ElMessage；不要把错误塞进角落 toast 就完事。

对比度底线：按钮文字对背景 ≥ 4.5:1（大字号 18px+ 可 3:1）；表单 placeholder、错误文字同样过 AA。主绿 `#27794f` 压白字 5.34:1，放心用。

## 8. 反 AI slop 禁令清单（红线）

以下模式在本项目**一律禁止**，code review 见到就打回：

1. **禁紫蓝渐变**、禁任何形式的"AI 紫/霓虹蓝"辉光、发光按钮。
2. **禁模糊彩色圆球/渐变团背景**（blur blob）。背景就是暖白纯色。
3. **禁 emoji 当装饰**。图标用 Element Plus Icons；表情符号不出现在 UI 文案里（用户自己聊天内容除外）。
4. **禁滥用玻璃拟态**：不堆 `backdrop-filter` 磨砂面板。遮罩层用半透明纯色即可。
5. **禁"居中 hero + 渐变大字"模板脸**：不做居中大标题 + 副文案 + 双按钮的营销页结构；LabX 首页是物料列表，不是 landing page。渐变文字全禁。
6. **禁 eyebrow 滥用**：不在每个区块标题上都加"小大写标签"。中文界面基本不需要 eyebrow。
7. **禁三列等宽特性卡片**这类营销页套路；列表就是列表，网格按内容数量来，不留空格凑阵。
8. **禁装饰性状态圆点**：圆点只在表达真实状态时出现（如在借/逾期），且一个区块至多一处。
9. **禁滚动提示**（"向下滚动探索"）、禁版本号页脚（v1.4.2 / Build 0048）、禁分区编号（01 / 02 / 03 当装饰）。
10. **禁假数据味文案**：不用"赋能/无缝/颠覆/下一代"这类空话动词；UI 文案说人话、说具体动作（"借出""归还""转人工审核"）。
11. **禁 div 拼假截图/假终端**当装饰；要展示就用真实界面或真实图片。
12. **禁超长破折号当设计元素**；中文排版用正常标点。
13. **禁每行都加 border 的长列表**：分隔线成组用、稀疏用，不做"十行十道线"的表格。
14. **禁无限循环动画与滚动监听驱动动画**；动画只在状态变化时发生。

> **豁免条款（队长 2026-08-12 明确拍板）**：开屏叙事页 `IntroOverlay.vue` 是仪式感场景，允许使用滚动驱动动画（GSAP scrub）、HUD 分区编号（01 / 物料流转 等）与"向下滚动"提示，不受红线 9、14 约束；粒子星座 canvas 属其氛围背景。以上元素仅限该组件，普通页面仍按红线执行。

## 9. 交付前 Pre-flight 检查表

页面重做或新页面上线前，逐条过，任何一条勾不上就是没做完：

- [ ] 颜色全部走 `var(--lx-*)`，组件里没有写死色值（grep `#` 和 `rgb(` 自查）
- [ ] 全页只有一个强调色（实验室绿），没有冒出的第二种强调色
- [ ] 没有踩第 8 节任何一条红线（重点自查：渐变、圆球背景、emoji、玻璃拟态、hero 模板脸）
- [ ] 字号全部落在字阶档位上，没有脱档的 15px/17px
- [ ] 间距全部落在 8px 基网上（4/8/12/16/24/32/48/64）
- [ ] 圆角符合刻度且同类组件全站一致
- [ ] 阴影只用了三档刻度，平级内容靠细边框分组
- [ ] 数字/编号用了 `.lx-num` 等宽字体
- [ ] 每个可交互元素有 hover/focus/active/disabled 态；focus 描边可见
- [ ] 按钮文字对背景对比度 ≥ 4.5:1；按钮文案一行内放得下不换行
- [ ] loading / empty / error 三态都做了，空状态带引导动作
- [ ] 动效全部在 150-400ms + ease-out 类曲线内，无 linear、无无限循环、只动 transform/opacity/颜色
- [ ] 系统开"减少动态效果"时页面可用（全局降级已兜底，但新 keyframes 要自查）
- [ ] `<768px` 实测单列不挤不破；`≥1280px` 内容不超 1200px 居中
- [ ] `npm run build` 通过；浏览器里真点过一遍（含管理端，全局覆盖不许把它弄崩）

## 10. 控制台主界面（第三轮，2026-08-12）

首页 `/` 重构为"控制台三栏"（`AskPage.vue`）：左轨能力矩阵 + 系统状态，中央对话控制台，右轨用户读数 + 物料精选 + 快捷功能。≥1280px 三栏，1024-1279px 中+右，<1024px 单列（对话在上，侧轨沉底）。

新增组件语言：

- **雷达徽标**：空状态欢迎区的纯 CSS 雷达（双环 + `conic-gradient` 扫掠 4.2s + 中心呼吸点），表达"助手待命/倾听"这一真实状态。
- **在线 LED / 库存状态点**：`led-pulse` 呼吸光晕，只表达真实状态（控制台在线、物料在库），借空物料不亮不动。
- **终端日志**：流式过程显化行加 mono `›` 前缀 + 左侧 2px 绿阶发线；provenance 从 el-tag 胶囊改为 mono 小标 + 状态点。
- **指令行**：欢迎区常用提问、能力矩阵、快捷功能统一为"mono 序号 + 文本 + ›"的命令行结构，发线分隔，hover 整行染浅绿，› 微移。
- **控制台头**：`LABX AGENT ONLINE` + 秒级遥测时钟（等宽数字不抖动）。
- **聚焦辉光**：输入框 focus 时 `0 0 0 4px var(--lx-green-glow-soft)` 微光，表达焦点状态。
- 新增令牌 `--lx-green-glow` / `--lx-green-glow-soft`（主绿派生透明档，深浅两主题各一份）。

> **红线豁免说明（对齐第 8 节，待队长复核）**：
> 1. 红线 14 禁无限循环动画——雷达扫掠、LED 呼吸、库存点呼吸是**持续状态表达**（待命/在线/在库），与 loading 跳动圆点同类，不属于装饰性循环；系统开"减少动态效果"时全局降级已覆盖。
> 2. 红线 9 禁分区编号当装饰——指令行 01-04、能力 C1-C4（方案 spec 里的机制真名）、快捷 01-03 是命令行语义的操作符标号，与 tabs 的 AGENT/MAT/REC 标注同源，不是分区装饰。
> 3. 红线 6 eyebrow——欢迎区 `LABX · EXPERIENTIAL AGENT` 全站仅此一处，是控制台标识而非区块标题套路。

## 11. 第四轮升级：浅色未来感细化 + 交互重排（2026-08-13）

本轮目标：保持浅色主基调（暖白底 + 单一实验室绿不变），把"科技感/未来感"做进组件细节，并重排交互与按钮层级。工具依据：本地 `taste-skill`（反 AI slop 清单）与 `redesign-skill`（先审计后定点修）驱动；视觉回归用 DSH vision-toolkit（截图问答 + pixel diff）+ Playwright 多视口截图（1440/1024/375）。

### 11.1 新增令牌（tokens.css）

- `--lx-btn-glow`：主按钮 hover 辉光环（主绿派生透明档，表达"通电"状态）。
- `--lx-edge-light`：深绿块上的内高光角标色（按钮内收版 `.lx-brackets` 语言）。
- `--lx-scan-line`：输入框聚焦扫描线色（一次性扫掠，表达焦点状态）。
- `--lx-skeleton-base` / `--lx-skeleton-shine`：骨架屏底色/扫光。

### 11.2 组件语言升级（element-overrides.css / style.css）

- **主按钮内收角标**：`.el-button--primary:not(.is-plain)` 用伪元素画四角内高光（仪器角标语言的按钮内收版），hover 加辉光环；`translateY(1px)` 按压反馈沿用。
- **输入聚焦扫描线**：输入框/选择器 focus 时底缘 1px 绿线一次性扫过（`lx-input-scan` 400ms ease-out，仅 transform）；替换原 focus 辉光为"扫描 + 辉光"双表达。
- **路由过渡**：`<transition name="page">` 400ms ease-out 淡入上移 6px（只动 opacity/transform，符合第 6 节）。
- **激活 tab 强化**：选中段加主绿描边 + 浅绿辉光（原仅白底，区分度不足）。

### 11.3 交互与按钮重排

- **物料列表即时筛选**：搜索改为本地实时过滤（无需点按钮），新增分类胶囊 chips（全部/各分类动态生成）+ `共 N 件` mono 读数；等级标签从 el-tag 改为双段式徽标（mono 代码 BASIC/ADV/PRO + 中文），三级色区分；卡片间距收窄到 8px。
