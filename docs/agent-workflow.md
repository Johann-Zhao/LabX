# LabX 智能体交互工作流（对话环节的规范）

> 本文件是智能体对话（`/api/agent/chat` 与前端"智能助手"页）的**交互契约**。
> 修改对话行为先改这里，再改 `backend/orchestrator.py`。
> 制定背景：模糊提问不能硬答（"我的电机不转"没说是什么电机）；本地知识库不可能覆盖所有物料，需要联网兜底。

## 三条原则

1. **先问清楚，再回答。** 回答所需的关键信息（槽位）缺失时，禁止直接给方案——先反问。
2. **本地优先，网络兜底，通用经验最后。** 本地知识库有的不用网络；网络检索不到的才用模型通用知识。
3. **每个回答必须标明出处**（provenance）：`local_kb` 本地知识库 / `web` 网络检索 / `model` 通用经验 / `offline` 离线兜底。

## 主流程（状态机）

```
用户消息
  → 意图识别（troubleshoot / recommend / inventory / chitchat）
  → 分支：
```

### troubleshoot（排障）

槽位：**故障物料**（必答）、**故障现象**（必答，要具体）

1. 从用户当前借用清单 + 消息文本定位物料（名称/型号/特征词匹配，匹配分见 orchestrator）
2. **槽位不全 → 逐槽位澄清**（每轮只问一个，问清为止，规则详见"澄清规则"）：
   - **物料缺失**（借用清单与目录都无匹配）→ 问物料（候选=借用清单+猜测+都不是）
   - **物料只是弱匹配**（全量目录特征词擦边命中，如"电机"匹配到"L298N 电机驱动模块"）→ 候选首位标注"（猜的）"请用户确认
   - **现象模糊**（只有"坏了/不行了"，没有"完全不转/读数为 0"这类具体现象）→ 问现象（常见现象 chips）
   - 用户可随时点"不用问了，直接回答"终止澄清
3. 槽位齐备 → **本地检索**该物料知识卡片/社区经验 → 有命中 → LLM 综合生成（provenance=local_kb，带卡片引用）
4. 本地未命中 → **联网检索**（优先 DeepSeek 原生 web_search，失败退回 DuckDuckGo）→ 有结果 → LLM 按检索内容生成（provenance=web，附来源链接）
5. 联网也失败 → LLM 通用知识回答（provenance=model，声明"本地未收录，以下为通用经验"）；LLM 整体不可用 → 预置兜底（provenance=offline）

### recommend（愿望到方案）

现有五步管线不变（意图理解 → 物料目录限定选择 → 库存校验 → 技能路径 → 一键预约），
结果在对话中以 BOM 卡片内联展示。项目描述过于模糊（少于 5 个字且无名词）时可反问一句想要什么功能。

### inventory（查库存）

现有流程不变（名称/型号/分类匹配物料 → 报库存位置）。

### chitchat（开放式问答）

无槽位检查，直接走"本地检索 → 联网检索 → 通用经验"阶梯（同 troubleshoot 的 3-5 步）。

## 澄清规则（细节）

- **逐槽位澄清，问清为止**：每轮只问一个缺失槽位（先物料、后现象），不合并发问、不设轮数上限——直到槽位齐备才回答
- 排障槽位：**故障物料**（系统内 ID 或用户自带的名称/型号）、**故障现象**（具体描述）
- 候选项做成可点击 chips（借用清单 / 常见现象），降低输入成本
- **"都不是，是我自己的物料"不等于信息已知**——它只是排除了系统内物料，必须再追问"它叫什么、什么型号"，拿到名称后按外部物料处理（禁止拿目录物料硬套），回答走"本地→联网"阶梯
- **自带物料命中相关物料资料时必须披露假设**：本地没有该物料的专属资料、只有相关物料（如驱动模块）的卡片时，回答开头要声明"本地没有它的专属资料，以下按最相关的方案排查"，结尾提示"实际驱动/接线不同就告诉我型号再细查"
- **引用卫生**：参考列表只保留与最高分同物料、或分数 ≥ 最高分 60% 的卡片，杜绝无关卡片混入
- 每轮澄清都附逃生项"**不用问了，直接回答**"：用户有权随时终止澄清，系统按当前已知信息作答并明示假设
- 澄清状态存后端内存（按 conv_id 的 `pending`：原始问题 + 已填槽位 + 正在收集的槽位），服务重启即失效——前端表现为"再问一次就好"，可接受

## 对话状态约定

- 前端进入对话页时生成 `conv_id`（页面生命周期内不变，刷新页面重新生成）
- 后端按 `conv_id` 保存 pending 状态（内存字典，演示规模无需落库）

## 回答展示约定（前端）

- provenance 徽标：local_kb=绿色"本地知识库"、web=蓝色"网络检索"、model=灰色"通用经验"、offline=黄色"离线兜底"
- 澄清消息：气泡 + 候选项 chips（点击即发送）
- 排障回答：保留"多智能体协作过程"steps 展示（澄清也记入 steps）
